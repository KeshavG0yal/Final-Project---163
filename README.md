# How Interest Rates and Inflation Relate to Sector Stock Returns and Bank Earnings

CSE 163 final project by Keshav Goyal.

## How to run

1. Install the libraries: `pip install -r requirements.txt`
2. Download and clean the data (needs internet; saves CSV files in `data/`):
   `python download_data.py`
3. Run the EDA (prints summaries, saves plots in `results/figures/`):
   `python eda.py`
4. Run the tests: `python test_eda.py`
5. Build the EDA report: `python build_report.py <this repo's URL>`

The `data/` folder in this repository already contains the downloaded CSV
files, so steps 3-5 work without internet access.
